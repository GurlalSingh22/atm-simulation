# 🏧 ATM Simulation - Python

A simple ATM simulation program built using Python with Package Architecture.

## 📁 Project Structure

```
atm_simulation/
├── atm/
│   ├── __init__.py       # package init file
│   ├── operations.py     # deposit, withdraw, balance logic
│   └── statement.py      # transaction history
├── main.py               # main menu (entry point)
└── README.md
```

## ▶️ How to Run

```bash
cd atm_simulation
python main.py
```

## 💡 Features

- PIN verification (3 attempts)
- Check balance
- Deposit money
- Withdraw money
- Mini statement with date and time

## 🛠️ Tech Used

- Python 3
- datetime module
- Package Architecture
